04 Campaign

The big idea

Launch with the winter school break, a busy period for family and domestic leisure trips, and keep it running as each new route opens.

Next to the Window

جنب الشباك

Travellers already film the view from their seat, so flynas asks them to post it with their route and seat. The best clips go inside Find My View, so the next traveller picks a seat based on a real passenger's view.

How it spreads

Passengers post a 10 second window clip with #جنب_الشباك and their route code; each week flynas features the top clips in the app and on its channels and gives the creator return tickets on that route (proposed reward).

Tests to run
  • Hook test on the hero reel: Arabic poll opener (شباك ولا ممر؟) versus a scenic first frame, measured by 3 second hold rate.
  • End card test on the same route reel: Book by the view versus a fares from message, measured by app click through.
  • Same route, two clips: creator footage versus real passenger footage, compared on saves and comments.

For an airline, a missed reply can send a traveler to a competitor, so X doubles as a fast service channel.

Before spending the budget, I'd test this

Do passenger window clips posted with a route code create more route searches than flynas fare graphics?

Method

4 week test on Snapchat Spotlight and Instagram: Next to the Window passenger clips versus fare graphics for the same routes, each with a tracked link

Sample

4 domestic routes, 24 posts, tracked link sessions to the booking page

What would confirm it

Window clips drive at least 30% more booking page sessions per 1,000 views than fare graphics
